# py-tools

a pile of random little python scripts. no theme. just stuff.

| file | what it does |
|------|--------------|
| `dice.py` | roll dice, like `3d6+2` |
| `passgen.py` | generate a random password |
| `asciiart.py` | turn text into big ascii letters |
| `guessing_game.py` | number guessing game |
| `textfx.py` | mess up text (leetspeak, mOcKiNg, reverse, etc) |
| `fib.py` | fibonacci / primes / factorials number toys |
| `stopwatch.py` | dumb terminal stopwatch |
| `coinflip.py` | flip a coin a bunch and show stats |
| `unitconv.py` | convert units (temp, length, weight) |
| `junk.py` | the official junk drawer, random pointless functions |

run any of them with `python3 py-tools/<file>.py`
